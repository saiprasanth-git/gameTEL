# ashtachemma
Current Game Rules
1. Setup
Players: 2 to 4 players.

Pawns: 4 pawns per player.

Board: A 5x5 grid with a spiral path moving from the outside inward.

Starting Position: All pawns start locked in a "Home Base" outside the main board.

2. Dice (Cowrie Shells)
The game uses 4 Cowrie shells.

Scoring:

1 mouth up = 1 point

2 mouths up = 2 points

3 mouths up = 3 points

4 mouths up = 4 points (+ Bonus Turn)

0 mouths up (All face down) = 8 points (+ Bonus Turn)

3. Spawning (Entering the Board)
Pawns cannot move immediately. They must be "unlocked" from the Home Base to enter the starting square.

Rolling an 8: Unlocks ALL inactive pawns at once.

Rolling a 4: Unlocks 2 inactive pawns.

Note: Spawning consumes the move value for those pawns (they enter the board at the start), but since 4 and 8 are bonus rolls, the player gets to roll again immediately.

4. Movement
Pawns move along a specific spiral path: Outer Ring → Inner Ring → Center (Fruit House).

Safe Zones (Cross Marked Boxes): Pawns cannot be captured on these tiles.

Outer Safes: The middle squares of each outer side.

Inner Safes: The diagonal squares in the inner ring.

Center: The Fruit House.

Stacking: Multiple pawns (same or different players) can sit on the same Safe Zone.

5. Capturing (Cutting)
If you land on a square occupied by an opponent's pawn (and it is not a Safe Zone):

The opponent's pawn is "killed."

Penalty: The killed pawn returns to Home Base, becomes Locked, and loses its "Inner Path" access. It must wait for a 4 or 8 to re-enter.

Reward: The capturing player gets a Bonus Turn.

Unlock: The specific pawn that made the capture gains "Inner Path Access."

6. The Inner Path (Fruit House Entry)
A pawn can only enter the inner circle (the path to the center) if it has captured at least one enemy pawn.

If a pawn has not captured anyone, it will keep circling the outer ring (or simply be blocked from entering the inner tiles).

7. Winning
A pawn finishes by reaching the exact center tile (Fruit House).

The first player to get all 4 pawns to the Fruit House wins the game.
